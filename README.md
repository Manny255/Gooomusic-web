# GoooMusic Web

Static Next.js website for GoooMusic public pages, including the product homepage, privacy policy, terms, and help center.

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

The project uses `output: 'export'`, so the production artifact is the `out/` directory.

## Environment

Copy `.env.example` to `.env.local` for local development when needed.
